# Kevin's Cookie Shop Tycoon

Open `index.html` in any modern web browser. No installation, internet connection, or build step is needed.

Alternatively, run `python3 -m http.server 8000` from this folder and visit http://localhost:8000.

Start with $100 and run your shop for 30 days. Cookies cost $0.50 to bake. Set the batch size, price, and advertising budget, then open for the day. Expenses are paid upfront; unsold cookies expire. Daily foot traffic, your price, and advertising determine demand. Advertising has diminishing returns and demand has a small random variation. The game ends after day 30 or when you cannot afford to bake one cookie.

Progress automatically saves in your browser when storage is available. Direct-file storage behavior varies by browser; use the local server for consistent saves. New game asks before resetting progress.
